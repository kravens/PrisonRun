# Free Samourai Prison Run — Arnhem

Event flyer for the **#FREESAMOURAI Prison Run**, a Noderunners × Bitcoin Runners side event.
Friday September 18th — meet 15:50, run 16:00 — from the Koepelgevangenis to Proeflokaal De Hoppenaar.

## Files

- `index.html` — the flyer. Fully self-contained (all images inlined); only needs internet for the map tiles and Leaflet. Ready for GitHub Pages.
- `prison-run-arnhem.gpx` — the official 5.02 km route track (source of the map's runner line).
- `breaking-out-bear.jpg` — bear artwork (background watermark).
- `logo-white.svg` — official Bitcoin Runners logo (white).
- `noderunners-logo-black.svg` — official Noderunners logo (black).
- `noderunners-bear-running.svg` — vector running-bear mascot (unused spare).
